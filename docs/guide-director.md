# Film Director

**Film Director** (`/production`, in the Film menu) is the whole production of the active Cast on
one page: what's made, what's waiting on you, what went wrong, and what automation did. It only
reads — every number comes from what the tools already keep, and opens the tool that owns it.

!!! note "Not the pose Director"
    **Direct a move…** on a Scene (beats on the 3D body) is still called the Director. Film
    Director is this page.

## What next

The top of the page lists what to do, most pressing first. Each item opens the tool at the exact
place — it never does the work for you.

| When | Opens |
| --- | --- |
| The Cast has no reference picture | The Cast page |
| Jobs failed or were lost (with the latest reason) | The Queue |
| A run paused (with why) | The run on the Scene page |
| A kept take you marked *Looks wrong* | That Scene |
| Takes to review — a Scene with takes and no keeper | That Scene |
| Continuity findings on kept takes | Cut's Continuity list |
| A Scene with no take yet | That Scene |
| A planned script scene with nothing made | That script |
| Coverage gaps in a script's shot lists | The Scene page |

Five show at a time; **Show all** lists the rest. When nothing waits, it says so.

## The overview

| Section | What it counts |
| --- | --- |
| **Scenes and takes** | Scenes rendering or being checked, with takes to review, kept, with no take yet, kept takes that look wrong, and in the Cut — each Scene listed with its state |
| **Script** | Script scenes and how many are planned, shots planned, made into Scenes, coverage to look at, and planned scenes with nothing made |
| **Jobs (last two days)** | Waiting, running, failed, lost or timed out, with the latest problems |
| **Automation** | The Scene page's run: its state, how far it got, why it stopped, and every step with its time (see [Runs](guide-scene.md#runs)) |
| **Continuity and the Cut** | Open findings on kept takes, saved versions, films cut and the last one |

Missing media and the pre-cut checks stay in [Cut](guide-film.md): they need the files themselves.
