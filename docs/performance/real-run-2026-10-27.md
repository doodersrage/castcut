## Findings

**D7 — a dialogue shot's Scene gets no beat** (new defect). `draftShots` puts the scene's action
only on its establishing shot; a dialogue shot carries its line but not what is happening, so
the Scene made from it has an empty Beat, and the Day still engine fills one in. Here the kitchen
line ("Coffee first.") was rendered as _checking the phone while leaning on the sill_, while the
wide of the same scene shows her pouring coffee. Proposed fix: a dialogue or reaction shot's
Scene takes the scene's first action as its beat (`shotSceneDraft`), with a unit test.

**D8 — a run's takes skipped their checks** (found afterwards, preparing V3; fixed the same
day). The run moved on as soon as a take landed, before the Face finish and the checks after it:
none of this run's 4 takes got a face score, and pose misses were never redone. That is also
why the run looked fast. After the fix, the same run on a fresh install: every take has face and
pose scores, two pose misses were redone, and the run took about 21 minutes instead of 4.

**Observations** (not defects; for V5 / V7):

- **Time between takes.** A take renders in 12–18 s, but the run spent 40–65 s between one take
  landing and the next being queued — and with D8 fixed, a take's checks and any redo come on
  top. The run's _about 4 min_ estimate counts renders only. Worth measuring with V7.
- **Missing model notice.** The Scene page said _This scene needs 1 file (40.9 GB): qwen image
  edit 2511 bf16 — for stills, face finish_. Takes rendered without it; whether the face finish
  was skipped quietly is not visible in the take. Worth a look with V3 (consistency).
- **Measure loudness on a silent film** is offered and answers _no sound to measure_ — correct,
  but the button could be left out when the film as cut says _Silent_.
- **Subtitles** are on for the review copy and Before cutting warns that no shot has any: the
  kitchen line is a still's line (spoken only once animated), so this is expected.
- **Dev only:** a hydration warning on the Cast page while an import navigated away (Next's
  streaming placeholder against `AmbientBackground`). Not checked on a production build yet.

## Not covered by this run

- Clips: Animate, Copy moves and the Director on a run's Scenes (the earlier Scene real-render
  phases cover them on single Scenes); a film with sound, so a real loudness figure.
- A second server: the package was imported in a second browser against the **same** server, so
  its media were _found at their address_ rather than stored anew. A true second machine needs a
  second data folder and server.
- Pause and Cancel on a real engine (the reload path was exercised; Pause and Cancel are covered
  by e2e against stubs).
- The human choice of keepers.

## Re-run

```bash
PROMPT_DATA_DIR=<empty folder> PROMPT_AUTH_ENABLED=false PROMPT_BIND_HOST=127.0.0.1 \
  npx next dev --webpack -H 127.0.0.1 -p 47923
SCENE_BASE=http://127.0.0.1:47923 SCENE_OUT=<out> SCENE_CASTS=<folder with mara.castcut.json> \
  SCENE_KEEP=first npx tsx scripts/scene-real-render.mts setup engine script shots run keep cut2 package
```

Leave out `SCENE_KEEP=first` to keep the takes yourself (the script waits up to an hour). Each
phase's time and problems are written to `<out>/report.json`; screenshots to `<out>/shots`.
